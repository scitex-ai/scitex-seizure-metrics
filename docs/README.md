# `docs/` — documentation sources

Documentation for `scitex-seizure-metrics`. Layout:

| Path | What |
| ---- | ---- |
| `sphinx/` | Sphinx site source (`conf.py`, per-module `.rst` autodoc pages, `quickstart.md`). Built to `sphinx/_build/html`; published to ReadTheDocs. The conceptual `math/` and `adr/` pages are symlinked in so they appear in the site toctree. |
| `math/` | Conceptual / mathematical derivation pages (MyST markdown). `sample_to_alarm.md` (analytic bridge), `sensitivity_tiw.md` (Karoly 2017 Fig 6 operating curve), `alarm_confusion_matrix.md` (the v0.2.0 alarm-regime confusion matrix, SPH/SOP framework, and detection-vs-forecasting guidance). |
| `adr/` | Architecture Decision Records — see `adr/README.md`. |
| `bridge_validation.{png,pdf}` | Monte-Carlo validation figure for the sample↔alarm bridge (regenerated by `examples/06_bridge_validation.py`). |
| `scitex-*.png` | Branding assets used by the README and the Sphinx theme. |

## Build the site locally

```bash
pip install -e ".[docs]"
make docs        # → docs/sphinx/_build/html/index.html
# or:
sphinx-build -b html docs/sphinx docs/sphinx/_build/html
```

The CI `docs-sphinx` job and ReadTheDocs build the same source. New public
modules/fields are picked up via autodoc once they appear in `__init__`
(or via a dedicated `.rst` page for internal modules such as
`classification.rst` / `report.rst`).
