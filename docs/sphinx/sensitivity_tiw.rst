sensitivity_tiw
===============

Empirical sensitivity vs time-in-warning trade-off — the field-standard
forecasting view (Karoly 2017 *Brain* 140:2169 Fig 6). Sweep the decision
threshold and trace seizure-level sensitivity against time-in-warning;
chance is the diagonal (sensitivity == time-in-warning). The empirical
complement to the analytic :doc:`bridge`. See
:doc:`math/sensitivity_tiw` for the chance-diagonal derivation and a
worked example.
